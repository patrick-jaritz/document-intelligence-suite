   - Environment variable: `PDF_PAGE_RENDER_URL`
   - Requires external service to be deployed (PyMuPDF/pdf2pic based)

2. **PageIndex Webhook:**
   - Webhook URL needs to be configured in PageIndex dashboard
   - Format: `https://your-domain.com/functions/v1/pageindex-webhook`

3. **Token Accounting:**
   - Implemented in `executionService.ts`
   - Supports OpenAI, OpenRouter, and Anthropic APIs
   - Tracks tokens_in and tokens_out per execution
